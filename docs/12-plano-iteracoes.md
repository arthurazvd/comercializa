# Plano Geral de Iterações

## 1. Objetivo

O planejamento do semestre do **Comercializa** está dividido em **seis iterações**, sendo duas por unidade. Cada iteração prevê pelo menos uma User Story sob responsabilidade principal de cada integrante.

## 2. Equipe

- Arthur Azevêdo
- José Samuel
- Marcus Vinícius

> A responsabilidade indicada é principal. Revisões, testes e integração continuam sendo responsabilidade coletiva da equipe.

## 4. Estratégia de acompanhamento

Ao final de cada iteração, a equipe deverá:

- verificar as User Stories concluídas;
- executar a suíte automatizada;
- registrar falhas e débitos técnicos encontrados;
- atualizar a cobertura quando aplicável;
- revisar o backlog da iteração seguinte;
- manter a documentação do projeto consistente com o código entregue.

## 5. Observação sobre o planejamento

O plano é incremental. User Stories já parcialmente implementadas no sistema podem ser utilizadas nas iterações para atividades de auditoria, correção, refatoração, ampliação de testes e validação dos critérios de aceitação, conforme o foco da disciplina de Teste de Software.
